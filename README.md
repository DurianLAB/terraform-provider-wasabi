# Terraform Provider for Wasabi

Fork of the [terrabitz/wasabi](https://github.com/terrabitz/terraform-provider-wasabi) provider with a [GetBucketRegion fallback fix](https://github.com/DurianLAB/terraform-provider-wasabi/pull/1).

## Project structure

```
.
├── .github/              GitHub Actions workflows (CI + GoReleaser releases)
├── aws/                  Provider source — resources, data sources, config, validators
├── docs/                 Auto-generated provider documentation
│   ├── data-sources/     Data source schemas
│   └── resources/        Resource schemas
├── tools/                Go tool dependencies (terraform-plugin-docs)
├── main.go               Provider entrypoint
├── go.mod                Go module dependencies
├── .goreleaser.yaml      Cross-platform release builds (linux/darwin/windows × amd64/arm64)
└── Makefile              Acceptance tests (TF_ACC=1 go test ./...)
```

### `aws/`

All provider logic lives here:

| File pattern | Purpose |
|---|---|
| `provider.go` | Provider configuration, endpoint setup, credential handling |
| `resource_aws_*.go` | S3 buckets, IAM users/policies/roles, access keys |
| `data_source_aws_*.to` | Read-only lookups (IAM users, policies, S3 buckets) |
| `config.go` | AWS client initialization (S3, IAM, STS endpoints) |
| `validators.go` | Input validation functions |
| `awserr.go` | Error handling utilities |
| `structure.go` | Flatten/expand helpers for complex attributes |

### `docs/`

Auto-generated by [terraform-plugin-docs](https://github.com/hashicorp/terraform-plugin-docs). Do not edit manually — regenerate with:

```bash
go run github.com/hashicorp/terraform-plugin-docs/cmd/tfplugdocs
```

## Building

```bash
# Local build
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o terraform-provider-wasabi

# Cross-compile for release
goreleaser release
```

## Testing

```bash
# Acceptance tests (requires live Wasabi credentials)
TF_ACC=1 go test ./... -v -timeout 120m
```

## Installation

### Terraform Registry

```hcl
terraform {
  required_providers {
    wasabi = {
      source  = "terrabitz/wasabi"
      version = "~> 4.1"
    }
  }
}
```

### Local build

```bash
# Build and install to ~/.terraform.d/plugins/
go build -o ~/.terraform.d/plugins/registry.terraform.io/terrabitz/wasabi/4.1.3/darwin_arm64/terraform-provider-wasabi
```

## What Wasabi supports

| Feature | Status |
|---|---|
| S3 buckets | ✅ (with caveats — see below) |
| IAM users, groups, policies, roles | ✅ |
| Access keys | ✅ |
| Bucket versioning | ✅ |
| Bucket public access block | ❌ Wasabi doesn't support `PutPublicAccessBlock` |
| S3 state backend via Terraform | ⚠️ Provider can't read bucket back (GetBucketRegion fix in this fork) |
